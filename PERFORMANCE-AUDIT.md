# cnote performance audit checklist

Source audit baseline: `d6e7fdc`. All findings start open. The audit established code paths and
scaling, not measured latency. Related fixes: [#44](https://github.com/caayd/cnote/pull/44) (wheel
damage and shadows), [#45](https://github.com/caayd/cnote/pull/45) (reveal repaint and cadence), and
[#46](https://github.com/caayd/cnote/pull/46) (first-reveal font initialization). Those fixes are
already merged; the items below track residual or independent work.

**P1**: fix first; an unbounded resource cost or a scaling cliff on a common path.
**P2**: important, with a narrower trigger or higher implementation risk.
**P3**: measure first or bundle with the owning change; tooling priorities apply to developer time.
Severity is an audit judgment, not a benchmark result. IDs are stable: cite them in PRs. Keep a box
open until the fix lands and its evidence is linked here. If evidence disproves a finding or a
tradeoff is intentional, record that disposition and evidence next to the box instead of deleting it.
Source locations refer to the baseline. Worktree and PR rules remain in [AGENTS.md](AGENTS.md).

**Decision needed** marks a proposed fix that would change behavior a comment or test pins down. Land
the behavior-preserving part first; the marked part needs the owner's sign-off. Functional bugs the
audit found are listed separately or noted on the item that found them.

## First-pass priorities

- [ ] **PERF-001 · P1 — Windows touchpad window-wrapper leak.** `src/platform/windows/PrecisionTouchpadQt.cpp:20–44,159–184,209–222` calls `QWindow::fromWinId()` twice per gesture output and again for some route probes; the wrappers are never released. Pass the actual Qt window handle into the adapter and use HWND only for Win32 calls. Verify flat Qt window counts through real pan, pinch, and inertia on mixed-DPI monitors; the synthetic sink bypasses this path.
- [ ] **PERF-004 · P1 — Growing freehand vector copied on every append.** `src/ui/InteractionRouter.cpp:618–645` copies the raw prefix even without a replacement shape. Keep one authoritative freehand buffer, with separate replacement geometry only as needed. Check long strokes with scratch-out disabled to isolate copy cost.
- [ ] **PERF-005 · P1 — Scratch recognition rescans the freehand prefix.** The default-enabled `src/ui/InteractionRouter.cpp:643–681` invokes `src/selection/ScratchOut.cpp:215–249` per append; length and resampling walk the prefix, and qualifying samples sort it for a hull. Track length incrementally, gate on cheap incremental state, and reuse buffers. Preserve the contract that release removes exactly what the preview marked.
- [ ] **PERF-006 · P1 — Erase and scratch-out scan the entire page per sample.** `src/ui/CanvasWidget.cpp:2858–2971` measures all text/math, scans raw stroke points before rejecting distant strokes, and smooths candidates again. Cache conservative page-space bounds and query the swept region or hull bounds before exact tests. Start with cached bounds; add a spatial index if candidate counts justify it.
- [ ] **PERF-007 · P1 — No raster byte budget at high zoom/DPR.** `src/render/PageRenderer.cpp:477–518,660–667`, `src/ui/CanvasWidget.cpp:583–620,1139–1167,1386–1396`, and `src/PdfBackend.cpp:107–135` allocate full pages and large preview images. Cap checked dimensions and aggregate bytes, retain a usable prior raster on failure, avoid retrying impossible allocations, and render visible tiles or bounded regions above the cap. Measure peak bytes at high zoom and DPR.
- [ ] **PERF-008 · P1 — Settings and quick-size drags write on every tick.** `src/ui/SettingsDialogQt.cpp:300–338,731–743` (palette and scaled sliders persist on each `valueChanged`), `src/ui/ToolbarWidget.cpp:450–457` with `src/qt/QtMainWindow.cpp:559–568` (quick-size drag saves on each pointer move), and `src/settings/SettingsStoreQt.cpp:1099–1129` synchronously replace the full settings file. Update visuals live and skip unchanged effective values. Keep atomic writes and error reporting; count commits for one drag. **Decision needed:** committing on release or after a debounce breaks the tested immediate-persistence contract (`tests/SettingsDialogQtTests.cpp:7,573–612`).
- [ ] **PERF-009 · P1 — Whole-page, unbounded undo for small mutations.** `src/qt/QtDocumentController.cpp:982–991,1097–1121` and `src/ProjectSession.h:26–58` retain before/after copies of ink points and rich text even for a one-object move; rasters are shared (`src/Document.h:52–58`), so the cost is objects, not pixels. Use affected-object deltas; reserve full snapshots for true page-wide edits. Compare only affected objects for no-op suppression; check retained bytes across repeated gestures. **Decision needed:** whole-page `ReplacePages` snapshots are documented reference parity (`src/qt/QtDocumentController.cpp:1116`) and asserted by tests (`tests/PersistenceSemanticsTests.cpp:876–878`, `tests/CanvasGeometryTests.cpp:734`); byte-accounted history would cap currently unlimited undo.
- [ ] **PERF-010 · P1 — Full project copied and compressed on the GUI thread.** `src/ProjectFile.cpp:715–771,824–849` stages raw and encoded copies and copies embedded PDF data through the conditional at `:730`. Remove redundant buffers and append PDF bytes by span; then stream or serialize on a worker from an immutable snapshot. Keep atomic replacement, and clear dirty state only for the saved revision. Measure UI latency and peak bytes for manual and automatic saves.
- [ ] **PERF-011 · P1 — PDF export rasterizes full-page text overlays and retains them.** `src/render/PdfExportQt.cpp:27–97` and `src/PdfBackend.cpp:670–677,758–811` allocate 4× full-page overlays even for a single text box. Crop to painted bounds, position with the PDF image matrix, and release buffers as soon as PDFium's ownership contract permits. Measure overlay bytes and export memory; verify pixel and placement parity.

## Canvas, ink, and interaction

- [ ] **PERF-003 · P2 — Whole-document canvas geometry on pointer samples.** `src/ui/CanvasWidget.cpp:362–490,1098,4342,4384` builds all page views for a one-page lookup, hit, focus, or paint. The cost is O(pages) per event at a few integer operations per page, not a cliff. Cache document geometry separately from pan, query the visible range, and pass the resolved view through hit, mapping, and dirty-region calculation. Preserve current pixel rounding; compare identical visible content in short and long documents.
- [ ] **PERF-012 · P2 — Local pointer actions request full canvas damage.** `src/ui/CanvasWidget.cpp:2416–2458,3226–3235,3330–3419` blankets press/release/cancel, line/oval replacement, and stroke commit with page or widget updates. Separate no damage from viewport damage and invalidate only old/new visual bounds. Verify actual `QPaintEvent::region()`, not just the requested rect.
- [ ] **PERF-013 · P2 — Smooth scroll drives full frame work every 8 ms.** `src/ui/CanvasWidget.cpp:3988–4050` runs viewport and chrome work on each tick. Schedule visual updates at display cadence while preserving elapsed-time motion. Compare paint/notification counts at 60 Hz and on a high-refresh display.
- [ ] **PERF-014 · P2 — No-op pan and pinch still request paint.** `src/ui/CanvasWidget.cpp:208–229,307–318` repaints unchanged zoom or pan; `src/ui/PrecisionInputRouter.cpp:92–97` compares zoom to `1.0` instead of the previous applied scale, which is a small logic bug as well as a cost. Skip unchanged state and test a real pinch return to base scale.
- [ ] **PERF-015 · P2 — Erase preview rebuilds growing pending state.** `src/ui/InteractionRouter.cpp:743–755`, `src/ui/CanvasWidget.cpp:3865–3874,4076–4180,4462–4485`, and `src/render/PageRenderer.cpp:398–402` repeatedly search, copy, regroup, and measure pending targets. Maintain per-page membership and bounds incrementally, and use direct or sorted membership for opacity checks.
- [ ] **PERF-016 · P2 — Erase preview rerenders the entire accumulated patch.** `src/ui/CanvasWidget.cpp:1197–1239` rerenders a growing union on membership change; `src/render/PageRenderer.cpp:129–145,387–439` still walks stroke points for culling. Diff added/removed targets, use cached bounds, and patch only affected regions in correct layer order.
- [ ] **PERF-017 · P3 — Disjoint damage collapses to one bounding rect.** `src/ui/CanvasWidget.cpp:1097–1110,4053–4074` uses the bounding rect for accumulation and paint decisions; the cost appears only for widely separated marks. Retain a `QRegion` where regions stay sparse, and avoid composing intervening pages. Check widely separated erase marks.
- [ ] **PERF-018 · P2 — Selection computes the same bounds for damage, hover, and paint.** `src/ui/CanvasWidget.cpp:3653–3668,3839–3841,4245–4384` recomputes outlines around updates and paints; `src/qt/QtDocumentController.cpp:1136–1295` already caches move bounds. Share gesture geometry and reuse it across consumers, preserving actual per-object clamping and handle extents.
- [ ] **PERF-019 · P2 — Transform restores objects and rerenders selection per sample.** `src/qt/QtDocumentController.cpp:1350–1505`, `src/ui/SelectionMath.h:535–567`, and `src/ui/CanvasWidget.cpp:1439–1444` restore selected objects, calculate affine coefficients inside point loops, and rerender vector content. Hoist coefficients, use transient offsets for translation, and reuse prepared paths/layouts when valid. Reflow text only when its layout inputs change.
- [ ] **PERF-020 · P2 — Lasso drag copies its full path; release tests unrelated geometry.** `src/ui/CanvasWidget.cpp:3441–3463,3558–3597,4183–4209,4443–4454` and `src/ui/SelectionMath.h:450–514` replay growing paths and can test each stroke segment against every lasso edge. Track incremental bounds/path, reject disjoint objects before smoothing, and index lasso edges only if needed. Keep concave and self-intersecting semantics.
- [ ] **PERF-021 · P2 — PDF text hover and drag repeat queries and paint whole pages.** `src/ui/CanvasWidget.cpp:2697–2743,3186–3210,3448–3454,4183–4192,4384–4437` re-probes negative anchors, duplicates endpoint scans, and repaints the page for live text selection. Cache a completed probe even on miss, resolve anchors and endpoints once, and dirty changed glyph regions. Index char boxes only if scans remain hot.
- [ ] **PERF-022 · P2 — Scratch coverage does exact math after the outcome is knowable.** `src/selection/ScratchOut.cpp:159–213` samples long segments and computes distances for every hull edge. Reject disjoint segments first, short-circuit interior queries, compare squared distances, and stop when remaining length cannot change the result. Preserve valid-geometry coverage.
- [ ] **PERF-023 · P2 — Stroke paths are rebuilt across hit-test and render consumers.** `src/selection/StrokeSmoothing.cpp:90–130,213–217`, `src/ui/SelectionMath.h:330–514`, and `src/render/PageRenderer.cpp:306–378` stabilize and smooth the same committed stroke repeatedly. Reuse centerlines under a correct content/sampling key, borrow raw points for identity sampling, and skip pressure filtering for geometry-only consumers.
- [ ] **PERF-024 · P2 — Dotted previews and ghost fades rerasterize complete strokes.** `src/ui/CanvasWidget.cpp:655–662,1447–1478,2500–2531` bypasses incremental ink for dotted strokes and draws fixed ghost geometry on each fade frame. Carry dash phase across segments and retain a bounded ghost raster for the fade. Verify seams and opacity parity.
- [ ] **PERF-025 · P3 — Live ink growth copies the accumulated surface.** `src/ui/CanvasWidget.cpp:693–740` reallocates and copies the surface when a stroke leaves it, growing to the needed area plus 96 device pixels of slack; the slack is a deliberate amortization (`:699–705`). Measure bytes copied for long strokes; use bounded tiles or geometric growth if copying dominates.
- [ ] **PERF-026 · P3 — Eraser trail and pressure mesh allocate and rescan.** `src/ui/EraserTrail.cpp:31–48,78–122`, `src/ui/CanvasWidget.cpp:2535–2573`, and `src/selection/InkOutline.cpp:137–240` trim and rescan short histories and allocate temporary outline data. Track the active head/bounds incrementally, reuse scratch buffers, and profile vertex counts before changing quality caps.
- [ ] **PERF-027 · P3 — Snapped shape output can be unnecessarily dense.** `src/selection/ShapeRecognition.cpp:199–215` persists points at fixed page-unit spacing. Count downstream points for large snapped shapes. The bounded recognizer itself is not the target. **Decision needed:** dense edges are what keep corners sharp under render-time smoothing (`src/selection/ShapeRecognition.h:33–37`), and tests pin point counts (`tests/ShapeRecognitionTests.cpp:275,365–374`); adaptive spacing changes drawn geometry unless the renderer learns corners.

## Rendering, thumbnails, and PDF

- [ ] **PERF-002 · P2 — Quadratic sidebar layout.** `src/ui/SidebarWidget.cpp:244–313,477–519,768–831` recomputes the preceding pages' heights for each item's top, before offscreen rejection. Each step is a few float operations, so the cliff needs hundreds of pages. Cache heights and prefix offsets by page geometry and item width; binary-search visible items, hit targets, and drop slots. Check warm-cache paint and reorder cost at increasing page counts.
- [ ] **PERF-028 · P2 — Sidebar cache misses block its opening animation.** `src/ui/SidebarWidget.cpp:477–663` renders visible misses inside paint. Schedule visible thumbnails outside animation paint and coalesce updates by revision. Compare first and warm opens of a dense PDF.
- [ ] **PERF-029 · P2 — Sidebar thumbnail invalidation and retention are too broad.** `src/ui/SidebarWidget.cpp:168–185,595–663` repaints the panel on any commit, rerenders thumbnails for edits they do not depict, and retains all visited thumbnails. Dirty only affected item rects, key on thumbnail inputs, and keep a byte-bounded cache. Evaluate incremental ink append only if misses still dominate.
- [ ] **PERF-030 · P2 — Canvas evicts offscreen pages immediately and bursts work on zoom settle.** `src/ui/CanvasWidget.cpp:583–620,1035–1043,1180–1192` rerenders pages on the return scroll and can replace all visible exact-scale surfaces in one paint. Keep a byte-bounded nearby-page cache and prioritize visible replacements across frames. Normalize equivalent scale keys only where pixel alignment stays correct.
- [ ] **PERF-031 · P3 — Warm page-surface hits still walk object and source content.** `src/render/PageRenderer.cpp:520–667` rehashes object headers, text, and LaTeX before answering a hit. Use a key covering page identity/epoch, scale/DPR, render settings, engine generation and transient exclusions. The structural fingerprint is deliberate (`src/render/PageRenderer.h:71–78`); audit mutation coverage before replacing structural checks.
- [ ] **PERF-032 · P2 — Small patches still request full PDF backgrounds.** `src/render/PageRenderer.cpp:39–65,394,497–518` culls objects but not the PDF background. Crop a warm cached raster or request a bounded region on a miss. Count PDF renders during a small erase or move patch.
- [ ] **PERF-033 · P2 — PDF background misses reopen the PDF and copy pixels twice.** `src/render/PdfiumBackgroundProvider.cpp:29–69` and `src/PdfBackend.cpp:107–135,540–569` reload the PDF and copy raster pixels through intermediate owners. Reuse a document handle with explicit source lifetime, render into owned pixels, and separate thumbnail and canvas budgets. Keep failure caching.
- [ ] **PERF-034 · P3 — PDF open and hydration parse/load more than necessary.** `src/document/LoadDocumentFile.cpp:29–42` and `src/PdfBackend.cpp:430–535` open for the attachment probe and ordinary load, then enumerate source pages during hydration; this is a cold-load cost only. Reuse the handle, load metadata and validate only referenced pages as appropriate, and represent an unreadable page's blank background without a full raster.
- [ ] **PERF-035 · P3 — One PDF text-cache miss evicts every entry at capacity.** `src/qt/QtDocumentController.cpp:994–1038` copies extraction output and clears the cache at 64 entries. Move the output, evict one entry at a time, and reuse the PDF handle; measure cold latency before adding prefetch.
- [ ] **PERF-036 · P3 — Transient erase/gesture images can outlive their use.** `src/ui/CanvasWidget.cpp:1218–1239,3876–3890` retains the erase patch after committing. Release patch/item buffers on finish, cancel, and session replacement; verify other transient state still cleans up correctly.
- [ ] **PERF-037 · P3 — Export fallback and page handles live longer than necessary.** `src/PdfBackend.cpp:670–677,721–739,803–811` retains created page handles and flattened fallbacks until the end; `src/render/PdfExportQt.cpp:27–58,99–158` does extra opaque composition/conversion on that path. Close or release resources when PDFium permits; bypass composition for an already suitable opaque source. Preserve atomic export and error reporting.

## Chrome, settings, and first use

- [ ] **PERF-038 · P2 — Broad `UpdateChrome()` fan-out on viewport changes.** `src/qt/QtMainWindow.cpp:315–335,2104–2203` refreshes title, actions, editor and overlays; `src/ui/ToolbarWidget.cpp:1577–1584,2539–2550` repaints even for unchanged format or colour. Split viewport, command and selection updates. Guard unchanged setters and skip hidden overlay work.
- [ ] **PERF-039 · P2 — Hidden New Page dialog rebuilds its recent swatches.** `src/ui/NewPageDialogQt.cpp:287–294,411–439` destroys and recreates swatches when broad chrome refresh calls `setDefaults()`. Update only on changed defaults or recent colours. **Decision needed:** deferring a hidden dialog's refresh to its next show breaks `tests/NewPageDialogQtTests.cpp:187–190`, which expects swatches right after `setDefaults()`.
- [ ] **PERF-040 · P3 — Toolbar hit testing recomputes layout.** `src/ui/ToolbarWidget.cpp:1587–1667` recomputes rects per control; `src/qt/QtMainWindow.cpp:1731–1773` can repeat the hit for hover and native hit codes. Compute layout once, cache measurements by real inputs, and reuse the hit. Invalidate old/new hovered or pressed controls instead of the whole band.
- [ ] **PERF-041 · P3 — Wheel configuration can bypass localized damage.** `src/ui/ToolbarWidget.cpp:827–839,2261–2271` issues full-client updates for unchanged geometry and entries; the repaint costs only while the wheel overlay is open. Guard equality and use wheel bounds for local changes. Exercise the wheel while toolbar geometry changes, not just during hover.
- [ ] **PERF-042 · P3 — Reveal runs duplicate host geometry passes.** `src/ui/ToolbarWidget.cpp:1888–1891` and `src/qt/QtMainWindow.cpp:642–643,1976–2018` can dispatch two geometry passes per tick of the reveal animation. Use one notification for each geometry change. Preserve the stack-order guard from #45.
- [ ] **PERF-043 · P2 — Unrelated settings recreate shortcut actions and reapply the shell.** `src/qt/QtMainWindow.cpp:765–801,854–892,1119–1135` handles all settings with the same path, including deleting and recreating seven tool actions. Diff changed fields and update existing bindings only when their sequences change.
- [ ] **PERF-044 · P3 — Settings controls refresh and normalize more than needed.** `src/ui/SettingsDialogQt.cpp:638–674,731–743,1014–1028` refreshes unrelated controls on every change and can repeat save-failure reporting (a bug: one failed drag can raise repeated error dialogs). Touch only affected controls and report a write failure once per interaction; refresh on show already exists (`:1118–1120`). For New Page HSL (`src/ui/NewPageDialogQt.cpp:301–376`), paint the swatch without repolishing its stylesheet or rebuilding unrelated controls. **Decision needed:** snapping the auto-save slider only on release breaks `tests/SettingsDialogQtTests.cpp:349–351`, which asserts snapping during the drag.
- [ ] **PERF-045 · P3 — Cold sidebar, popup, and text assets remain outside band warmup.** `src/ui/ToolbarWidget.cpp:958–961,1912–1925` warms only the band and drops wheel sprites on hide; `src/text/TextEditingQt.cpp:34–90` lazily registers bundled fonts. Compare first and second uses; warm only the verified bottleneck, and retain shadow sprites only if latency justifies memory.
- [ ] **PERF-046 · P3 — Repeated icon, style, and native metrics lookups.** `src/ui/ChromeAssetsQt.cpp:567–638` resolves resource paths before cached icon lookup; `src/qt/QtMainWindow.cpp:199–267,1760–1761,1957–1971` re-scans text fragments and queries frame metrics. Use complete icon keys and resolved paths, one selection-fragment pass, and metrics invalidated by HWND/DPI changes.
- [ ] **PERF-047 · P3 — Per-window app-wide toolbar filters multiply dispatch.** `src/ui/ToolbarWidget.cpp:1406–1412,2622–2665` visits events outside its window. Count dispatches with many views before narrowing scope; keep outside-click dismissal and shortcut behavior.

## Text and LaTeX

- [ ] **PERF-048 · P2 — Text layout-cache hits still build an auto-width document.** `src/text/TextLayoutQt.cpp:57–102,129–228,292–314` caches line data but not resolved width, and drawing builds fresh documents. Cache width/height together; reuse offset maps and prepared draw layout for matching inputs. Remove unused key dimensions and avoid copying line strings for bounds queries. Count document builds during hit tests, transforms, and redraws.
- [ ] **PERF-049 · P2 — Editor caret movement and edits repeat whole-document work.** `src/ui/InlineMathTextEdit.cpp:157–328` captures full snapshots and reconciles every formula; internal format changes can trigger a canvas refit (`src/ui/CanvasWidget.cpp:1742,1818–1832`). Reuse a single model/map snapshot, update cursor offsets without recapture, reconcile sorted ranges, and refit once per actual content/style edit.
- [ ] **PERF-050 · P3 — Inline-math scanning can be quadratic on unmatched dollars.** `src/text/InlineMath.cpp:37–92` rescans a line for later valid closers; the cost is bounded by line length, so it needs a pathological line. Scan once or precompute next valid closes, preserving escapes, `$$`, line boundaries, and currency rules.
- [ ] **PERF-051 · P3 — LaTeX cache hits still widen and revalidate source.** `src/latex/LatexEngine.cpp:197–240` converts and scans before lookup; `src/text/InlineMathQt.cpp:39–112,122–153` queries validation, sizing, and draw through different sizes. Key hits on original source, cache validation separately, and reuse measured placeholder metrics. Preserve engine-generation invalidation and layout parity.
- [ ] **PERF-052 · P3 — Overlay placement runs in paint and completion has two triggers.** `src/ui/CanvasWidget.cpp:1483–1495,1527,1751–1755,1926–2019` recopies/parses preview source, reapplies masks/geometry, and refreshes completion from text and caret signals. Update preview on source/style changes, place on geometry changes, and coalesce completion. Test zoom/settle changes for caret and wrap parity.
- [ ] **PERF-053 · P3 — Editor-local undo and copy capture full content.** `src/ui/InlineMathTextEdit.cpp:147–155,185–206,304–328` retains full snapshots and walks all content for selection copy. Use bounded history or text/span deltas and map only the selected range when feasible. Check formula source, styles, and caret restoration.

## Model, persistence, and application lifecycle

- [ ] **PERF-054 · P2 — Erase repeatedly shifts objects and emits per-page commits.** `src/qt/QtDocumentController.cpp:1508–1562` erases by index; `src/ui/CanvasWidget.cpp:3876–3889` commits per page. Selection is single-page by design and cut is already one action (`src/qt/QtDocumentController.cpp:2095–2125`), so the target is the erase drag. Compact once per collection and produce a single history record/notification per gesture. Bug: erasing does not remap surviving selection indices (`:1563–1577`), which can leave them stale; fix that with the compaction.
- [ ] **PERF-055 · P2 — Page defaults allocate a raster just to compare it.** `src/ui/PageDefaultsQt.cpp:48–79` builds a full 1.5× solid raster per page and `src/qt/QtDocumentController.cpp:1887–1950` snapshots pages. Use explicit solid-background metadata or a reusable buffer, and capture history only for changed pages. Test unchanged and mixed-source Apply to All Pages.
- [ ] **PERF-056 · P2 — File load reads and copies full input more than necessary.** `src/qt/QtDocumentIo.cpp:14–59`, `src/document/LoadDocumentFile.cpp:18–24`, and `src/ProjectFile.cpp:60–68,798–815` sniff via a separate open and copy whole-file bytes. Sniff a single read into the final owner and release embedded attachment/source buffers as soon as no longer needed.
- [ ] **PERF-057 · P2 — XPRESS stages bytes on both encode and decode.** `src/document/XpressCodec.cpp:396–473,477–545,555–609` decodes into a temporary and stages encoded chunks. Write into the final buffer or bounded chunks, reuse block scratch, and enforce a load working-memory budget. Preserve CRC, framing, raw fallback, and legacy compatibility. Profile tree decoding and match copying only after removing staging copies.
- [ ] **PERF-059 · P3 — Model IDs and history make avoidable scans and copies.** `src/qt/QtDocumentController.cpp:433–447,1119–1120,1764–1780,2185–2195` scans all text IDs and copies pages through braced initializers and an intermediate clipboard copy. Use a session ID high-water mark and direct vector insertion; access clipboard pages by reference where ownership allows.
- [ ] **PERF-060 · P3 — Bulk page history shifts vectors repeatedly; rejected changes bump epochs.** `src/document/HistoryReducer.cpp:44–185` uses per-page mutation calls for batches and touches epochs before some changes can fail (a bug: a rejected change still invalidates the page). Batch page and epoch shifts, preserve page order/current-page semantics, and bump epochs only after success.
- [ ] **PERF-061 · P3 — Page rotation physically rebuilds stored rasters.** `src/Document.cpp:493–577` and `src/qt/QtDocumentController.cpp:1826–1885` copy pixels and retain old rasters through history. Measure large stored backgrounds and consider cache-friendly quarter-turns. Preserve formats and undo semantics. **Decision needed:** storing rotation as metadata changes the file format, and `rotated_pdf_persistence_qt` asserts identical pixels after reopening.
- [ ] **PERF-062 · P3 — Clipboard duplicates payloads and swizzles pixels unnecessarily.** `src/document/SelectionClipboardQt.cpp:36–84,115–218` copies decoded objects and encoded bytes and swizzles straight BGRA/ARGB per pixel. Move decoded payloads, reserve output (`src/document/SelectionClipboardCodec.cpp:93–194`), and use validated row copies on matching byte layouts. Bound reservations by remaining records and preserve portability.
- [ ] **PERF-063 · P3 — Startup and new-window work can run before it is useful.** `src/main.cpp:403–458` initializes MicroTeX before showing a window and can show before loading the requested file or settling size. New views can reread settings and create a throwaway blank session. Profile first-frame stages; attach directly to an existing session, share parsed settings, and keep service-error diagnostics and package self-checks.
- [ ] **PERF-064 · P3 — Recent-file and session lookup do redundant filesystem work.** `src/shell/AppManager.cpp:106–123,224–256` compares paths with filesystem equivalence during session lookup; `src/qt/QtMainWindow.cpp:1059–1082` does the same per recent entry, then saves settings and rebuilds the menu even when the path is already first. Skip unchanged recent-file writes and use stable file identity where possible without breaking aliases.

## Native input, capture, and build tooling

- [ ] **PERF-065 · P3 — Native frame routing and history queries repeat work.** `src/platform/windows/PrecisionTouchpad.cpp:233+` queries history twice; `src/platform/windows/PrecisionTouchpadQt.cpp:135–222` repeats conversion and route work and installs one app-wide native filter per adapter. Reuse query buffers, map once, and cache routing only for a gesture with stable ownership. Consider sharing dispatch if many-window profiles justify it.
- [ ] **PERF-066 · P3 — Capture pays for intermediate images and per-step work.** `src/shell/CaptureDriver.cpp:356+,441–489,566–631` uses intermediate images, scans top levels without a grab, and allocates per typed character. Measure capture throughput before reusing render targets, cached per-step targets, or parsed key data. Keep the event-loop turns needed for deterministic frames.
- [ ] **PERF-067 · P3 — Package runs build tests and stage an unused install.** `.github/workflows/package.yml:81–98,148–166` builds `all`, installs to `stage/`, then CPack installs again; nothing reads `stage/`, though the header comment (`:8–11`) presents it as part of the packaging sequence, so it may be a deliberate install-rule check. Build `--target cnote`, keep or drop the stage install as an explicit choice (updating the header), and align Linux dependency setup with CI while retaining artifact verification.
- [ ] **PERF-068 · P3 — Superseded CI builds continue and repeat cold work.** `.github/workflows/ci.yml:31–38,107–125,175–189` has no run cancellation or compiler cache; Qt is already cached (`cache: true`), but PDFium is downloaded and verified on every run. Cancel superseded PR runs, and cache compiler outputs and the PDFium SDK with toolchain/digest keys. Preserve the shipping static build and validation.
- [ ] **PERF-069 · P3 — CI and preset tests run serially.** `.github/workflows/ci.yml:119–125,185–189` and `CMakePresets.json:40–43` set no parallelism. Try limited parallelism after checking timing-sensitive tests; `selection_clipboard_qt` owns the real OS clipboard and the native-window tests assert focus, so they need dedicated serial constraints (`RUN_SERIAL` or `RESOURCE_LOCK`).
